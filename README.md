# Формы на React: два подхода

Привет, ревьюер и просто случайный путник! 👋

Это мой ответ на задачу "React Forms" от RS School — небольшая демка, где я экспериментирую формами сразу двумя способами:

- **неконтролируемая форма** — старый добрый `ref` и `FormData`, никакого React Hook Form, только хардкор и валидация при сабмите (спойлер: будет больно);
- **форма на React Hook Form** — с живой валидацией, отключённой кнопкой при ошибках и почти магией.
